# Инфо о работе скрипта
## Работа скрипта поделена на несколько модулей

## Основные модули
1. **code.py**: - Запуск основной функции (валидация на пустой файл и отлов ошибок)
2. **validate.py** - Получает данные с командной строки и дланные с файла, валидирует их в необходимый тип данных
3. **filter.py** - Получает уже валидированные данные и фильтрует их
4. **aggregate.py** - Получает уже валидированные данные и агрегирует их
5. **tests.py** - Тесты
